# Pavan P - Personal Portfolio

A professional and responsive personal portfolio website built with React and Vite. It showcases my technical skills, education, experience, projects, and contact information.

## Live Portfolio

The portfolio will be deployed using GitHub Pages.

## Features

- Responsive design for desktop, tablet, and mobile
- Professional landing page
- About Me section
- Technical Skills section
- Experience section
- Education section
- Projects showcase
- Project GitHub links
- Resume download
- Contact section
- LinkedIn and GitHub links
- Smooth navigation and animations
- Mobile-friendly navigation

## Projects

### YelpCamp

A full-stack campground web application where users can create, view, and review campground listings.

**Technologies:** Node.js, Express.js, MongoDB, Mongoose, EJS, Passport.js, Cloudinary

### Paryavaran Kavalu

A smart waste management Android application that allows users to report waste and helps administrators manage and update reported waste.

**Technologies:** Kotlin, Android Studio, Firebase, Firestore, Firebase Storage, Google Maps API

### T-Shirt Shopping Web Application

A full-stack e-commerce application for browsing T-shirts and placing orders, with an admin interface for managing products and viewing orders.

**Technologies:** HTML, CSS, JavaScript, Node.js, Express.js, MongoDB, Mongoose

### Human Action Recognition

A computer vision project that recognizes human actions using a deep learning model.

**Technologies:** Python, OpenCV, ResNet, ONNX
